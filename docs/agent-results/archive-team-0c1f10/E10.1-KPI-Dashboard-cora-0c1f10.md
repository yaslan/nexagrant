## Features Implemented

✅ **6 KPI Cards**
- Total Offers (project count)
- Success Rate (funded/above-threshold %)
- Average Score (excellence, impact, implementation avg)
- Person-Days (sum(Effort.hours) / 8)
- G0→G2 Timeline (avg days between gate decisions)
- Active Modules (ON status count)

✅ **Date Filtering**
- Dynamic date range from URL params (`?from=…&to=…`)
- Default: last 30 days
- Filters all 6 KPI metrics

✅ **Tab Navigation**
- Overview: 6 KPI cards grid
- Trends: Recharts line chart (Offers vs. Success Rate)
- Export: CSV download button

✅ **CSV Export**
- Format: Date, Metric, Value
- Downloads as `fabrika-dashboard-YYYY-MM-DD.csv`
- Functional via `handleExport()` in Dashboard
